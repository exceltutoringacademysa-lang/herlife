# HerLife memory assets

This folder is intentionally awaiting the original user-supplied binary files. The storyboard and first-time film code have already been committed.

To add the assets to this public GitHub repository, extract **HerLife-private-memory-media.zip** (provided in the conversation) and use GitHub **Add file → Upload files** to place all 30 extracted files directly in `public/memories/`. Do not upload the ZIP as a single file. They include 27 numbered photographs, 2 numbered videos and `soundtrack.mp3`. Keep the exact filenames.

Every media file committed here is publicly downloadable through GitHub and through the deployed website. GitHub repository history may retain copies even if deleted later. Get the subject's permission and appropriate music licensing before publishing.

The first-time film checks `/memories/001-memory.jpg` to confirm media exist, then displays captions from `src/memoryStory.ts`. It will not auto-launch while no photograph has been uploaded.
